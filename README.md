# Hibersafe

This application runs on Docker using Java 17 and PostgreSQL with the pgvector extension.

## Infrastructure Architecture

The system is fully containerized and orchestrates three primary services via Docker Compose:

1. **`hibersafe-frontend`**: React application running on port `8081`.
2. **`hibersafe-backend`**: Spring Boot REST API running on port `8080`.
3. **`hibersafe-db`**: PostgreSQL 16 image equipped with the `pgvector` extension.

---

## How to Load the Database Dump File

If you have a pre-existing dataset dump (`database_dump.sql`), follow these steps to securely wipe any auto-generated Hibernate schemas and cleanly populate the database.

### Step 1: Open your Terminal and Navigate to the Dump Directory
Move into the directory on your local Mac where your `database_dump.sql` file is located (e.g., your Downloads folder):

> `cd ~/Downloads`

### Step 2: Clear any Conflicting Auto-Generated Tables
Wipe out the public schema to clear out tables auto-generated by Hibernate during initial boot sequences. This prevents primary key conflicts and foreign key constraint violations during data entry:

> `docker exec -i hibersafe-db psql -U postgres -d rag_db -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"`

### Step 3: Re-enable the pgvector Extension
Since dropping the schema removes tracking extensions, re-verify that the required `pgvector` utility is actively initialized within the fresh schema:

> `docker exec -i hibersafe-db psql -U postgres -d rag_db -c "CREATE EXTENSION IF NOT EXISTS vector;"`

### Step 4: Stream the SQL Dump into the Container
Execute the command below to inject your entire local data dump into the running PostgreSQL container instance:

> `docker exec -i hibersafe-db psql -U postgres -d rag_db < database_dump.sql`

## Accessing the Application

Once the services are active and the database is populated, you can interact with the ecosystem at these endpoints:

- **Frontend Interface:** http://localhost:8081/?estrategia=B&id=1
- **Interactive API Documentation (Swagger UI):** http://localhost:8080/swagger-ui/index.html
